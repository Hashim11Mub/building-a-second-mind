# Build a signup prototype from a saved plan

1. Read signup-plan.md. Current decision and Success check are the current requirements. Decision log explains history.
2. Create signup.html in this folder as one self-contained HTML file.
3. Give the email field a visible label. Use inline CSS and JavaScript and a local confirmation.
4. Check the page against the saved requirements.
5. Report which files you read, what you changed and which checks you actually performed. Say if a check was not performed.

Use signup-plan.md and this workflow. If a requirement is unclear, ask before changing it. Write only signup.html. Do not install packages, use remote assets, make network requests or add persistent storage.
