# Team signup page

Build a waitlist page for an imaginary team project.

## Current decision

Ask for exactly one thing: an email address.

Button label: Join waitlist.

## Success check

- One visible, required email field.
- A Join waitlist button.
- Invalid or empty email is rejected.
- Valid email shows a local confirmation.
- No network requests, external assets or persistent storage.

This is a local prototype. It does not subscribe anyone or store submissions.

## Decision log

- Initial version: email only, to keep the first version easy to try.
