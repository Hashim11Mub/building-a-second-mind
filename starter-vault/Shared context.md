# Shared context

A useful handoff carries the goal, latest decision, reasons, sources and unfinished next step.

[[signup-plan]] is a readable source for this project. A new compatible agent can read it when file access is configured. This does not automatically synchronise ChatGPT or Claude chat histories, and it does not mean every tool reads every file on every turn.

Obsidian is a view and editor over the files. A coding agent works with the files through its own tools and permissions.
