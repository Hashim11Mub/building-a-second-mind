KNOW WHAT IS DOING WHAT

The words, simply.

Model

Generates the answer or proposes the next action.

Harness

The software that calls the model, manages context and permissions, runs allowed tools and returns results.

Loop

Ask the model → run an allowed tool → return its result → ask again, until a stopping condition is reached.

Saved context

The relevant facts, evidence and current decision the next session can read. It needs deliberate retrieval.
